# فك الالتباس

> سؤال واحد، خياران أو ثلاثة، ثم توجيه. لا استجواب.

---

## ١. قاعدة السؤال الواحد

اسأل فقط إذا كان الجواب **يغيّر المهارة**. وإن كان يغيّر التفاصيل فقط، افترض واذكر الافتراض.

| يغيّر المهارة | لا يغيّرها |
| :--- | :--- |
| مقال أم خبر أم بحث؟ | العنوان طويل أم قصير؟ |
| قصة أم سيناريو؟ | اسم البطل؟ |
| طفل أم بالغ؟ | عدد الفصول؟ |
| ترجمة أم تأليف؟ | اللهجة؟ |
| خطبة أم مقال ديني؟ | المذهب (يغيّر الفقه لا المهارة) |

**قاعدة:** المذهب في الخطبة سؤال إلزامي، وإن لم يغيّر المهارة، لأنه يغيّر المحتوى.

---

## ٢. بنك الأسئلة

### ٢.١ «اكتب نصاً»

> «ما نوع النص: قصة، مقال، خبر، بحث، أم شيء آخر؟»

### ٢.٢ «اكتب قصة»

> «لمن القصة، وما طولها التقريبي: قصة قصيرة، رواية، أم قصة للأطفال؟»

### ٢.٣ «اكتب مقالاً»

> «هل تريده مقال رأي/عمود، مقالاً أدبياً، أم بحثاً أكاديمياً؟»

### ٢.٤ «اكتب بحثاً»

> «ما مستواه: بحث تخرج، فصل من رسالة، أم ورقة مؤتمر؟ وما نظام التوثيق؟»

### ٢.٥ «اكتب سيناريو»

> «هل هو فيلم قصير، فيلم طويل، مسلسل، أم مسرحية؟»

### ٢.٦ «اكتب للأطفال»

> «ما العمر المستهدف، وهل الشكل كتاب مصور أم قصة نصية؟»

### ٢.٧ «ترجم»

> «ما اتجاه الترجمة، وما المجال: عام، أدبي، تقني، أم قانوني؟»

### ٢.٨ «اكتب خطبة»

> «ما المذهب، وما المناسبة، وما المدة التقريبية؟»

### ٢.٩ «اكتب خبراً»

> «هل هو خبر عاجل، تقرير، تحقيق، أم حوار؟ ولمن الوسيط؟»

### ٢.١٠ «اكتب إعلاناً»

> «ما المنتج، ومن الجمهور، وما الوسيط، وما الدليل الذي يمكننا استخدامه؟»

### ٢.١١ «راجع النص»

> «هل تريد تحريراً لغوياً، نقداً بنيوياً، أم تدقيقاً للوقائع؟»

### ٢.١٢ «حسّن الأسلوب»

> «هل المشكلة في اللغة والركاكة، أم في الصورة البلاغية؟»

---

## ٣. الافتراضات الآمنة

إن لم يسأل المستخدم، افترض ما يلي **واذكره**:

| الطلب | الافتراض |
| :--- | :--- |
| «قصة» | قصة قصيرة، ١٠٠٠–١٥٠٠ كلمة، جمهور بالغ |
| «مقال» | مقال رأي، ٨٠٠–١٠٠٠ كلمة |
| «بحث» | ورقة بحثية قصيرة، توثيق APA |
| «سيناريو» | فيلم قصير، ٥–١٠ مشاهد |
| «أطفال» | ٦–٨ سنوات، قصة نصية |
| «ترجمة» | إنجليزي → عربي، مجال عام |
| «خطبة» | جمعة، ١٥–٢٠ دقيقة — **لكن اسأل المذهب** |
| «خبر» | خبر رقمي، ٤٠٠–٦٠٠ كلمة |
| «إعلان» | منشور سوشيال + نسخة طويلة |

**قاعدة:** الافتراض الآمن لا يغيّر المهارة. وإن كان يغيّرها، اسأل.

---

## ٤. الالتباسات الشائعة

### ٤.١ «قصة» و«رواية»

- القصة القصيرة: حدث واحد، شخصية محدودة.
- الرواية: عالم أوسع، فصول، تطور طويل.

**حالياً:** كلتاهما إلى `story`، مع تنبيه أن الرواية تحتاج مهارة مستقلة لاحقاً.

### ٤.٢ «مقال» و«خبر»

- المقال: رأي/تحليل بصوت الكاتب.
- الخبر: حدث بمصادر.
- الفرق: هل تبدأ بـ«أرى» أم بـ«قال»؟

### ٤.٣ «بحث» و«تقرير»

- البحث: سؤال ومنهج وتوثيق.
- التقرير: عرض معلومات لوظيفة محددة.
- التقرير الإخباري: `media`. التقرير الأكاديمي: `academic`.

### ٤.٤ «نقد» و«تحرير»

- النقد: تقييم فني/فكري.
- التحرير: إصلاح لغوي وبنيوي.
- قد يجتمعان: `editing` ينتج تقرير تحرير، و`story`/`essay` يفسر البنية.

### ٤.٥ «خطبة» و«محاضرة دينية»

- الخطبة: منبر، مخاطبة جمهور، بناء خطابي.
- المحاضرة: تعليم/شرح.
- كلتاهما قد تستخدم `khutba` إذا كان الوعظ هو الغالب، مع تعديل البنية.

### ٤.٦ «إعلان» و«محتوى»

- الإعلان: بيع/تحويل.
- المحتوى: تعليم/ثقة.
- إذا كان الطلب «منشوراً تعريفياً» فقد يكون `copywriting` أو `media`؛ اسأل عن الهدف.

### ٤.٧ «ترجمة» و«تعريب»

- الترجمة: نقل من لغة إلى أخرى.
- التعريب: نقل/تكييف إلى العربية، وقد يشمل المصطلح.
- كلتاهما `tarjama`، مع توضيح درجة الحرية.

---

## ٥. متى لا تسأل

- الطلب واضح النوع والمخرج.
- الافتراض الآمن لا يغيّر المهارة.
- المستخدم قال «اكتب ما تراه» — هنا اختر زاوية واذكرها.
- الطلب قصير لكنه يحمل محفزين واضحين.

## ٦. متى ترفض

| الطلب | الرد |
| :--- | :--- |
| «أفتني في حكم…» | «هذه المهارة لا تفتي؛ يمكنني كتابة خطبة أو مقال، بمراجعة مختص.» |
| «اكتب بحثاً طبيًا وأثبت أن الدواء آمن» | «لا أختلق أدلة؛ أحتاج مصادر ومراجعة مختص.» |
| «اكتب خبراً عن حادث لم يحدث» | «لا أختلق خبراً؛ يمكنني كتابة سيناريو تدريبي واضح.» |
| «انتحل مقالة فلان» | «لا أنتحل؛ يمكنني كتابة نص أصلي بأسلوبك.» |
| «اكتب قصيدة» | «مهارة الشعر قيد التطوير؛ يمكنني مساعدتك في الصورة البلاغية أو قصة.» |

## ٧. قالب سؤال واحد

```text
سؤال: ...
خيارات:
١. ...
٢. ...
٣. ...
افتراضي إن لم تجب: ...
```

**مثال:**

> «هل تريد مقال رأي، أم تقريراً إخبارياً، أم بحثاً أكاديمياً؟ إن لم تحدد، سأفترض مقال رأي من ٨٠٠ كلمة.»
