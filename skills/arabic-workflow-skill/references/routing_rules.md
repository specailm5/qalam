# قواعد التوجيه والتعارض

> تُقرأ مع `SKILL.md` و`registry.json`. الغرض: اختيار مهارة واحدة أساسية، ومنع تحميل الحزمة كلها.

---

## ١. شجرة القرار

```text
هل الطلب عن اللغة نفسها (نحو/أسلوب/بلاغة)؟
├─ نعم → grammar / writing / balagha
└─ لا
   هل الطلب ترجمة؟
   ├─ نعم → tarjama
   └─ لا
      هل الطلب خطبة أو وعظ؟
      ├─ نعم → khutba (اسأل المذهب)
      └─ لا
         هل الطلب نص ديني غير الخطبة؟
         ├─ نعم → khutba أو رفض الفتوى
         └─ لا
            هل الطلب خبر/تقرير/تحقيق/حوار؟
            ├─ نعم → media
            └─ لا
               هل الطلب إعلان/تسويق؟
               ├─ نعم → copywriting
               └─ لا
                  هل الطلب أكاديمي (بحث/رسالة/توثيق)؟
                  ├─ نعم → academic
                  └─ لا
                     هل الطلب طفل/يافع؟
                     ├─ نعم → children-story
                     └─ لا
                        هل الطلب سيناريو/فيلم/مسرح؟
                        ├─ نعم → screenwriting
                        └─ لا
                           هل الطلب قصة/رواية؟
                           ├─ نعم → story
                           └─ لا
                              هل الطلب مقال/عمود/خاطرة؟
                              ├─ نعم → essay
                              └─ لا
                                 هل الطلب تحرير/تدقيق؟
                                 ├─ نعم → editing
                                 └─ لا → اسأل سؤالاً واحداً
```

---

## ٢. أولويات الاختيار

| الأولوية | القاعدة |
| :--- | :--- |
| ١ | **المخرج** يسبق الموضوع: «حرّر» ≠ «اكتب». |
| ٢ | **الجمهور** يسبق النوع: طفل ≠ بالغ. |
| ٣ | **الوسيط** يسبق النوع: فيلم ≠ رواية. |
| ٤ | **الغرض** يسبق الشكل: خبر ≠ مقال رأي. |
| ٥ | **الخطر** يسبق السرعة: خطبة/طب/قانون. |

---

## ٣. مصفوفة التعارض

### ٣.١ مقال أم خبر أم بحث؟

| العلامة | المهارة |
| :--- | :--- |
| «رأي»، «موقف»، «أسلوب شخصي»، «عمود» | `essay` |
| «حدث»، «مصدر»، «تحقق»، «خبر عاجل» | `media` |
| «فرضية»، «منهج»، «توثيق»، «مراجعة أدبيات» | `academic` |
| «خاطرة»، «تأمل»، «يوميات» | `essay` |

**سؤال حاسم:** «هل تريد نصاً يعبّر عن رأي، ينقل حدثاً، أم يقدّم بحثاً موثقاً؟»

### ٣.٢ حكاية أم حكايات أطفال أم سيناريو؟

| العلامة | المهارة |
| :--- | :--- |
| «قصة قصيرة»، «رواية»، «حبكة» | `story` |
| «حكايات للأطفال»، «عمر ٦»، «كتاب مصور» | `children-story` |
| «سيناريو»، «مشهد»، «فيلم»، «مسلسل» | `screenwriting` |
| «مسرحية» | `screenwriting` (حتى تُنشأ مهارة المسرح) |

**سؤال حاسم:** «لمن؟ وبأي وسيط؟»

### ٣.٣ تحرير أم نقد أم مراجعة؟

| العلامة | المهارة |
| :--- | :--- |
| «صحح»، «دقق»، «حذف الحشو» | `editing` |
| «ما رأيك؟»، «قيّم»، «نقد» | `editing` (تقرير تحرير) |
| «راجع بحثاً» | `academic` + `editing` |
| «راجع ترجمة» | `tarjama` + `editing` |

**قاعدة:** `editing` يشخّص ويصلح. وإذا كان الخلل في النوع نفسه، أضف مهارة النوع.

### ٣.٤ بلاغة أم أسلوب؟

| العلامة | المهارة |
| :--- | :--- |
| «استعارة»، «تشبيه»، «كناية»، «صورة» | `balagha` |
| «أسلوب»، «ركاكة»، «عَرَنْجِيَّة»، «فصحى» | `writing` |
| «تكلف»، «غموض», «حشو» | `editing` أولاً |

**قاعدة:** `balagha` لا تُحمَّل إلا إذا كان السؤال عن الصورة أو الزينة. و`writing` خط أساس أصلاً.

### ٣.٥ ترجمة أم كتابة؟

| العلامة | المهارة |
| :--- | :--- |
| «ترجم»، «تعريب»، «English to Arabic» | `tarjama` |
| «اكتب بالعربية» | `writing` + النوع |
| «راجع الترجمة» | `tarjama` + `editing` |

**قاعدة:** الترجمة تبدأ بـ`tarjama`، ثم `writing` و`grammar`، ولا تُعامل كتأليف حر.

### ٣.٦ خطبة أم مقال ديني؟

| العلامة | المهارة |
| :--- | :--- |
| «خطبة جمعة»، «منبر»، «عيد» | `khutba` |
| «مقال عن الدين»، «خاطرة إيمانية» | `essay` |
| «فتوى»، «حكم شرعي» | رفض: ليست فتوى |

**قاعدة:** الخطبة تستلزم سؤال المذهب أولاً. والمقال الديني لا يستلزمه، لكنه لا يفتي.

### ٣.٧ إعلان أم خبر؟

| العلامة | المهارة |
| :--- | :--- |
| «إعلان»، «شعار»، «حملة»، «بيع» | `copywriting` |
| «خبر»، «بيان»، «تقرير» | `media` |

**قاعدة:** البيان الصحفي قد يكون `media`، لكن المحتوى المدفوع `copywriting` ويجب تمييزه.

### ٣.٨ أكاديمي أم تقرير؟

| العلامة | المهارة |
| :--- | :--- |
| «بحث»، «أطروحة»، «توثيق»، «مراجعة أدبيات» | `academic` |
| «تقرير إداري»، «تقرير فني» | `academic` (مؤقتاً) أو رفض إن كان تقنياً |
| «تقرير إخباري» | `media` |

**قاعدة:** التقرير التقني كان سيكون `technical`، وقد أُلغي. لا تُوجِّه إليه.

## ٤. الطلبات المركّبة

### ٤.١ التسلسل لا التحميل المتزامن

```text
طلب مركب = مهام صغيرة مرتبة.
```

| الطلب | التسلسل |
| :--- | :--- |
| «اكتب قصة ثم سيناريو» | story → screenwriting |
| «اكتب مقالاً ثم حرّره» | essay → editing |
| «ترجم ثم دقّق» | tarjama → writing → grammar → editing |
| «اكتب خطبة ثم أضف أبياتاً» | khutba → (إذن الشعر) → writing |
| «اكتب إعلاناً ثم منشوراً» | copywriting → copywriting (نفس المهارة، وسائط مختلفة) |
| «اكتب بحثاً ثم ملخصاً» | academic → academic |

### ٤.٢ قاعدة الحد

لا تُحمِّل أكثر من **مهارة نوعية واحدة** في المرحلة الواحدة. المساندة لا تتحول إلى أساسية.

### ٤.٣ ترتيب التسليم

```text
النوع → خط الأساس → التمرير النهائي
```

مثال:

```text
children-story → writing → grammar → editing
```

## ٥. الثقة والتراجع

| الحالة | التصرف |
| :--- | :--- |
| تطابق واضح (٣ محفزات+) | وجّه مباشرة |
| تطابق محتمل (محفزان) | وجّه مع ذكر الافتراض |
| تطابق ضعيف (محفز واحد) | اسأل سؤالاً واحداً |
| لا تطابق | اسأل عن النوع |
| تعارض قوي | اسأل عن المخرج |

**قاعدة:** لا تسأل إذا كان الافتراض آمناً. ولا تفترض إذا كان الخطأ مكلفاً.

---

## ٦. عقد التسليم

بعد اختيار المهارة:

1. أعطِ بطاقة التوجيه.
2. حمّل خط الأساس.
3. حمّل المهارة الأساسية.
4. اتبع تعليماتها.
5. مرّر الناتج على `editing`.
6. لا تُعِد كتابة ما أنتجته المهارة من عندك.

**قاعدة:** التوجيه يقرر «من يكتب»، لا «ماذا يُكتب».
