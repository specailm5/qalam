أي مهارة؟

حدد النية، ثم حمّل أقل عدد من المهارات.

ما هذه المهارة؟

مهارة توجيه تُحمَّل أولاً. لا تكتب القصة ولا المقال ولا الخبر؛ بل تعرف ماذا يريد المستخدم، ثم تختار المهارة أو المهارات التي تكتب.

خط الأساس: arabic-writing-skill + arabic-grammar-skill دائماً. ثم مهارة نوعية واحدة. ثم arabic-editing-skill قبل التسليم.

لماذا لا نُحمِّل الـ١٣ كلها؟

لأن كل مهارة تحمل سياقاً ومصادر وقواعد. تحميلها كلها يفسد الاختيار ويستهلك السياق. التوجيه يقلّص الحزمة إلى ما يخدم الطلب فقط.

For English readers

An intent-router meta-skill for the Arabic skill suite. It loads first, extracts the user's intent (genre, deliverable, audience, medium, risk), then selects the smallest correct set of skills and their order. arabic-writing-skill (anti-العرنجية) and arabic-grammar-skill are always-on; arabic-editing-skill is the final pass. It contains the registry of every repository URL and install command, and it does not write the content itself. Works with Claude Code, Codex, Antigravity and VS Code agent harnesses.

المراجع

هذه مهارة ميتا، لا تُعلِّم جنساً أدبياً. سجلّها هو references/registry.json، ومصادرها هي مهارات المنظومة نفسها. ولا تنطبق عليها قاعدة «٢–٤ كتب» لأنها لا تُدرِّس بلاغة ولا نحواً.

قلم — مهارة ميتا تحدد نية المستخدم وتختار المهارات، ولا تكتب المحتوى.
